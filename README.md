# BAIKU (バイク) — فروشگاه لاستیک و روغن موتورسیکلت

سایت فارسی و راست‌چین با HTML، Tailwind CSS v4، Vanilla JavaScript و Vite (بدون فریم‌ورک).
هویت بصری: پوستر موتورسواری ژاپنی با قرمز، مشکی، خاکستری و سفید، و تیترهای درشت.

> ⚠️ **همه‌ی محصولات، برندها، قیمت‌ها و موجودی‌ها نمونه‌اند** (`demo: true`) و داده‌ی سازگاری موتورسیکلت‌ها (`bikes.js`) عمداً خالی است. تسویه‌حساب و ورود هم نمایشی‌اند.
> تصویر موتور در Hero یک **تصویر برداری موقت** است (`src/image/hero-bike.svg`).

## اجرا

```
npm install
npm run css:watch    # ترمینال اول: ساخت output.css با Tailwind
npm run dev          # ترمینال دوم: سرور Vite
```
نسخه‌ی نهایی: `npm run build` — انتشار روی GitHub Pages: `npm run deploy`
(آدرس مخزن در `base` فایل `vite.config.js` تنظیم می‌شود).

## صفحه‌ها

| صفحه | کار |
|---|---|
| `index.html` | خانه: Hero، فیلتر سایز لاستیک جلو/عقب، دسته‌بندی‌ها، پرفروش‌ها، بنرها، درباره |
| `tires.html` / `oils.html` | لیست با فیلتر، جستجو و مرتب‌سازی |
| `parts.html` / `accessories.html` | قطعات یدکی و اکسسوری (فعلاً «به‌زودی»، چون محصولی ثبت نشده) |
| `product.html?id=...` | جزئیات محصول |
| `checkout.html` | تسویه‌حساب نمایشی |
| `guide.html` | راهنمای خواندن سایز لاستیک و گرید روغن (از فوتر در دسترس است) |

## هدر و فوتر

هدر و فوتر یک بار در `src/js/layout.js` نوشته شده‌اند و همه‌ی صفحه‌ها فقط دو تگ خالی (`<header id="site-header">` و `<footer id="site-footer">`) دارند.
گزینه‌های منوی «دسته‌بندی محصولات» در آرایه‌ی `CATEGORIES` همان فایل هستند. هر صفحه‌ی جدید را در `vite.config.js` هم ثبت کنید.

## ساختار `src/`

- `data/` — `tires.js`، `oils.js`، `bikes.js`
- `js/` — `layout.js` (هدر/فوتر/منو)، `common.js`، `search.js`، `listing.js`، `product-card.js`، `specs.js`، `finder.js`، `panels.js` (سبد و ورود) و یک فایل برای هر صفحه (`*-page.js`)
- `css/main.css` — رنگ‌ها، فونت‌ها و کامپوننت‌ها
- `image/` — تصاویر موقت SVG

## رنگ و فونت

- رنگ‌ها در `@theme` فایل `main.css`: `bk-red` ‏(#E50000)، `bk-red-dark` ‏(#900B01)، `bk-bg`، `bk-surface`، `bk-fg`، `bk-line`، `bk-muted`.
- هر عنصر با کلاس `on-dark` همان کلاس‌ها را با رنگ‌های تیره می‌گیرد (هدر، فوتر، کشوی سبد، بخش‌های مشکی).
- تیتر فارسی: `font-fa` (Estedad ExtraBold، با پشتیبان Vazirmatn). تیتر لاتین: `font-display` (Anton).
- برای فونت محلی، بلوک کامنت‌شده‌ی `@font-face` در `main.css` را فعال کنید.

## چطور تغییر بدهم؟

- **محصول واقعی:** در `tires.js` / `oils.js` ردیف‌ها را عوض کنید و `demo: true` را بردارید. فیلترها، جستجو و فیلتر سایز صفحه‌ی اصلی از همین داده‌ها ساخته می‌شوند. مقدار نامعلوم را `null` بگذارید.
- **عکس Hero:** یک عکس موتور بدون پس‌زمینه (PNG) در `src/image/` بگذارید و مسیر `<img class="hero-bike">` را در `index.html` عوض کنید. افکت سیاه‌وسفید با CSS اعمال می‌شود.
- **سازگاری موتورسیکلت:** فقط از دفترچه‌ی سازنده، در `bikes.js` با `verified: true` و `source`.
- **محصول برای قطعات یدکی و اکسسوری:** فعلاً صفحه‌هایشان «به‌زودی» است؛ وقتی داده دارید می‌توانید مثل `tires.html` لیست‌شان کنید.

## پالت رنگی نهایی و تصاویر (آخرین به‌روزرسانی)

همه‌ی رنگ‌ها فقط در `src/css/main.css` (بخش `@theme static`) تعریف شده‌اند:

| توکن | رنگ | کاربرد |
|---|---|---|
| `bk-bg` | `#C8C8C8` | پس‌زمینه‌ی اصلی و غالب |
| `bk-surface` | `#CACACA` | هدر، فوتر، کارت‌ها و سکشن‌های ثانویه |
| `bk-red` | `#880A03` | دکمه‌ها، خط‌ها، hover و تأکید (نه متن) |
| `bk-fg` | `#080808` | تمام نوشته‌ها |
| `bk-white` | `#FFFFFF` | فقط فیلدهای فرم و نوشته‌ی روی دکمه‌ی قرمز |

- هدر، فوتر و هیچ سکشنی پس‌زمینه‌ی مشکی ندارد. برای تغییر رنگ‌ها فقط همین فایل را ویرایش کنید.
- لوگو: `src/image/logo.png` (در `layout.js` برای همه‌ی صفحه‌ها). فایل اصلی در `src/image/original/` است.
- Hero: `src/image/hero.jpg`؛ متن و دکمه‌ها HTML هستند. برای تغییر، همان فایل را جایگزین کنید (نسبت پیشنهادی ≈ ۲۵۷۶×۹۰۶).
- تفاوت `#C8C8C8` و `#CACACA` بسیار کم است؛ جداسازی کارت‌ها با خط و سایه‌ی ملایم انجام می‌شود.

اجرا: `npm install` ← `npm run dev` ؛ ساخت: `npm run build`.
