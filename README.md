# BAIKU (バイク) — فروشگاه لاستیک و روغن موتورسیکلت

سایت فارسی و راست‌چین با HTML، Tailwind CSS v4، Vanilla JavaScript و Vite (بدون فریم‌ورک).

> ⚠️ **همه‌ی محصولات، برندها، قیمت‌ها و موجودی‌ها نمونه‌اند** (`demo: true`) و داده‌ی سازگاری موتورسیکلت‌ها (`bikes.js`) عمداً خالی است. چیزی تأییدنشده به‌عنوان اطلاعات واقعی نمایش داده نمی‌شود. تسویه‌حساب و ورود هم نمایشی‌اند.

## اجرا

```
npm install
npm run css:watch    # ترمینال اول: ساخت output.css با Tailwind
npm run dev          # ترمینال دوم: سرور Vite
```
ساخت نسخه‌ی نهایی: `npm run build` — انتشار روی GitHub Pages: `npm run deploy`
(آدرس مخزن در `base` فایل `vite.config.js` تنظیم می‌شود).

## صفحه‌ها

| صفحه | کار |
|---|---|
| `index.html` | خانه: هیرو، یابنده‌ی محصول، دسته‌ها، پرفروش‌ها، برندها، بنرها، درباره، راهنما |
| `tires.html` / `oils.html` | لیست با فیلتر، جستجو و مرتب‌سازی |
| `product.html?id=...` | جزئیات محصول |
| `compare.html` | مقایسه (تا ۳ محصول هم‌دسته) |
| `wishlist.html` | علاقه‌مندی‌ها |
| `checkout.html` | تسویه‌حساب نمایشی |
| `guide.html` | راهنمای خواندن سایز لاستیک و گرید روغن |

هدر و فوتر در هر صفحه تکرار شده‌اند (مثل پروژه‌ی Faray). اگر منو را عوض کردید، در همه‌ی فایل‌های `.html` عوض کنید. هر صفحه‌ی جدید را در `vite.config.js` هم ثبت کنید.

## ساختار `src/`

- `data/` — `tires.js`، `oils.js`، `bikes.js` (داده‌ها)
- `js/` — `common.js` (منو/جستجو/سبد)، `search.js` (جستجوی هدر)، `listing.js` (موتور فیلتر)، `product-card.js`، `store.js` (علاقه‌مندی/مقایسه)، `specs.js`، `finder.js`، `brands.js`، `panels.js` (سبد و ورود)، و یک فایل برای هر صفحه (`*-page.js`)
- `css/main.css` — رنگ‌ها (`bk-*`)، کامپوننت‌ها و فونت
- `image/` — تصاویر موقت SVG

## چطور تغییر بدهم؟

- **محصول واقعی:** در `tires.js` / `oils.js` ردیف‌ها را عوض کنید و `demo: true` را بردارید. فیلترها، جستجو، برندها و یابنده خودکار از همین داده‌ها ساخته می‌شوند. مقدار نامعلوم را `null` بگذارید تا «ثبت نشده» نمایش داده شود.
- **سازگاری موتورسیکلت:** فقط از دفترچه‌ی سازنده، در `bikes.js` با `verified: true` و `source` (الگو داخل فایل است).
- **عکس:** `image` هر محصول را به فایل واقعی در `src/image/products/` تغییر دهید.
- **فونت محلی:** در `main.css` خط `@import` فونت را بردارید و بلوک `@font-face` را از کامنت دربیاورید.
- **فیلتر جدید:** یک خط به `groups` در `tires-page.js` یا `oils-page.js` اضافه کنید.
